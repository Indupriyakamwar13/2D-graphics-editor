# 2D Graphics Editor

## Description
A simple 2D Graphics Editor written in C using a 2D character array for drawing basic shapes.

## Features
- Draw Rectangle
- Draw Circle
- Draw Line
- Draw Triangle
- Add Objects
- Delete Objects
- Modify Objects
- Display Picture

## How to Run
1. Compile:
   ```bash
   gcc project.c -o project
2. Run:
   ```bash
   ./project
